# ShopZone SPA

A React single-page e-commerce app built with Vite and React Router.

## Local development

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## GitHub Pages deployment

This repo is configured to deploy to GitHub Pages at:

https://Adityakandregula.github.io/MISSION-6

To deploy:

```bash
npm run deploy
```

## Notes

- The app uses `basename="/MISSION-6/"` in `BrowserRouter` so it works correctly on GitHub Pages.
- `vercel.json` is also included for Vercel deployment.
